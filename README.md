## 📌 Problem Statement

Insider threats are among the most challenging cybersecurity risks because attackers already have authorised access to organisational systems. Traditional security tools often fail to detect malicious insider activities until significant damage has occurred.

Our solution, **Autonomous Threat Hunter**, leverages Artificial Intelligence and User & Entity Behaviour Analytics (UEBA) to continuously monitor user behaviour, identify suspicious activities, assign dynamic risk scores, and provide intelligent threat explanations with actionable security recommendations.

---

## 🎯 Project Objective

To develop an AI-powered cybersecurity solution capable of:

- Detecting insider threats in real time
- Monitoring user behaviour continuously
- Identifying suspicious activities using AI
- Calculating dynamic risk scores
- Generating AI-powered threat explanations
- Helping security teams respond faster to security incidents

## 🔄 Workflow

1. Collect user activity logs.
2. Analyse behavioural patterns using AI.
3. Detect anomalies and suspicious activities.
4. Calculate a dynamic risk score.
5. Generate AI-powered threat explanations.
6. Display insights on the dashboard.
7. Alert the security administrator for high-risk events.
